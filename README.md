# Al Hammadi Law Firm Website

Static bilingual (Arabic/English) website prototype for Dr. Ahmad Al Hammadi Law Firm & Legal Consultancy.

## Preview locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

The site is fully static and can be deployed directly to GitHub Pages, Netlify, Vercel or any standard web host.
